## GitCode SDK 私有部署改造方案

### 问题分析

当前 SDK 存在以下阻碍私有部署的问题：

| 问题 | 位置 | 影响 |
|------|------|------|
| 硬编码公网 URL | `client.go:17`, `oauth.go:15` | 无法自动适配私有实例 |
| 无环境变量支持 | 全局 | 无法通过 `GITCODE_URL`/`GITCODE_TOKEN` 配置 |
| `Client` 缺少 `SetBaseURL()` | `client.go` | 构造后无法修改 base URL |
| `NewClientFromOAuthToken()` 丢失 base URL | `oauth.go:111` | OAuth 流程后客户端指向公网 |
| `OAuthClient` 无便捷构造函数 | `oauth.go` | 私有部署需手动调 `SetBaseURL()` |
| 测试辅助不支持自定义 URL | `gitcode_test.go` | 集成测试只能跑公网 |

### 改造内容

#### 1. 新增环境变量支持 — `client.go`

新增 `resolveBaseURL()` 和 `resolveToken()` 内部函数，支持从环境变量读取配置：

```
GITCODE_URL   → 自定义 API base URL（如 https://gitcode.example.com/api/v5）
GITCODE_TOKEN → 认证 Token
```

优先级：**显式参数 > 环境变量 > 默认值**

修改 `NewClient(token)` 逻辑：若 token 为空且 `GITCODE_URL` 已设置，则自动从 `GITCODE_TOKEN` 读取。

#### 2. `Client` 新增 `SetBaseURL()` 方法 — `client.go`

```go
func (c *Client) SetBaseURL(baseURL string) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.baseURL = strings.TrimRight(baseURL, "/")
}
```

与 `OAuthClient.SetBaseURL()` 保持一致的模式。

#### 3. 新增 `NewClientFromEnv()` 便捷构造函数 — `client.go`

```go
// NewClientFromEnv creates a client from GITCODE_TOKEN and optionally GITCODE_URL environment variables.
// Returns nil if GITCODE_TOKEN is not set.
func NewClientFromEnv() *Client {
    token := os.Getenv("GITCODE_TOKEN")
    if token == "" {
        return nil
    }
    if baseURL := os.Getenv("GITCODE_URL"); baseURL != "" {
        return NewClientWithBaseURL(baseURL, token)
    }
    return NewClient(token)
}
```

#### 4. `OAuthClient` 新增 `NewOAuthClientWithBaseURL()` 构造函数 — `oauth.go`

```go
func NewOAuthClientWithBaseURL(clientID, clientSecret, redirectURI, baseURL string) *OAuthClient {
    o := NewOAuthClient(clientID, clientSecret, redirectURI)
    o.baseURL = strings.TrimRight(baseURL, "/")
    return o
}
```

#### 5. 修复 `NewClientFromOAuthToken()` 丢失 base URL 的 bug — `oauth.go`

```go
// Before:
func NewClientFromOAuthToken(token *OAuthToken) *Client {
    c := NewClient(token.AccessToken)  // ❌ 永远用 DefaultBaseURL
    return c
}

// After: 新增 OAuthClient 参数，传递 base URL
func (o *OAuthClient) NewClientFromOAuthToken(token *OAuthToken) *Client {
    return NewClientWithBaseURL(o.baseURL+"/api/v5", token.AccessToken)
}
```

同时保留旧的顶层函数作为兼容（deprecated）。

#### 6. 更新测试辅助函数 — `gitcode_test.go`

```go
func getTestClient(t *testing.T) *Client {
    t.Helper()
    if baseURL := os.Getenv("GITCODE_URL"); baseURL != "" {
        return NewClientWithBaseURL(baseURL, testToken)
    }
    return NewClient(testToken)
}
```

### 向后兼容性

- 所有现有 API 保持不变
- `NewClient(token)` 行为不变（仍使用 DefaultBaseURL）
- `NewClientWithBaseURL()` 行为不变
- `NewClientFromOAuthToken()` 保留为 deprecated，新增方法版本替代
- 环境变量仅在显式参数未提供时生效
